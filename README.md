# Luau:B

> .shik stands for Sorshik Horshik Iorshik Korshik (probably)

Luau:B *(Luau: Borshikified)* is a programming language based off Luau that meant to bring Roblox Studio to **your computer**. It can work with files, create GUI, and pretty much everything you would expect from a programming language.<br>
IDE included.<br>
<sub><sup>Fun fact: Luau:B works with .shik files</sup></sub>
